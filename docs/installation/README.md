# Install on macOS with Claude Desktop

This illustrated walkthrough sets up a **new Obsidian vault** and the Stud.IP MCP
without changing an existing vault. The graphics are generic diagrams, not screenshots;
Claude Desktop labels and settings can change between versions.

## Before you start

- macOS with Claude Desktop and Obsidian installed.
- Python 3.10 or later.
- Firefox installed (the MCP opens a dedicated Firefox profile for Stud.IP sign-in).
- Access to your institution's Stud.IP server.

Anki is optional and covered in [Step 7](07-anki.md); reMarkable handwritten notes are
optional and covered in [Step 8](08-remarkable.md). Both MCPs are separate from this
repository.
