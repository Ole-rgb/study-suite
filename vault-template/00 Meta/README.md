# Meta

Use this folder for learner-wide information that is stable across courses:

- `knowledge/` — durable learning preferences or reference notes.
- `resources/` — reusable study resources and links.
- `templates/` — blank course and note templates.
- `connections.md` — approved cross-course concept connections.

Keep semester-specific schedules and active course facts in each course's `Course.md`.
Do not store secrets, browser state, or MCP update snapshots here.
